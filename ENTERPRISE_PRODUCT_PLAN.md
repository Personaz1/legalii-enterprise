# LEGALII Enterprise Product Plan

## Product
LEGALII Enterprise — private legal AI platform for law firms.

## Value proposition
- On-prem/local-first deployment
- Client data never leaves firm boundary by default
- Structured legal workflows (intake, completeness checks, risk flags, reports)
- Auditability and controlled access

## Enterprise pillars
1. Security & privacy baseline
2. Deployment standardization
3. Governance and audit trail
4. Legal workflow templates

## Packaging targets
- `enterprise/docker-compose.enterprise.yml`
- `enterprise/.env.enterprise.example`
- `enterprise/README.enterprise.md`
- `enterprise/policies/*`

## Delivery mode
- Single command bootstrap for pilot
- Hardened profile for production
- Explicit cloud-off default
